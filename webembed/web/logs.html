Alexa-Erkennung: Hilfe

Alexa (ab 2019) erwartet den Hue Bridge-API auf Port 80. EchoLox läuft auf Port 8079; LoxBerry nutzt Apache2 auf Port 80.

Das Installations-Script richtet den Proxy automatisch ein. Falls das fehlgeschlagen ist, manuell:

# 1. Apache2-Proxy-Config erstellen:
cat > /etc/apache2/conf-available/echolox-hue.conf << 'EOF'
ProxyPreserveHost On
ProxyPassMatch ^(/api(/.*)?|/description\.xml|/hue_logo[^/]*|/favicon\.ico)$ http://127.0.0.1:8079$1
EOF

# 2. Module und Config aktivieren, Apache2 neu laden:
a2enmod proxy proxy_http
a2enconf echolox-hue
apache2ctl graceful

Danach Discovery-Port auf 80 in den Einstellungen setzen und EchoLox neu starten.
